# Shared sources

Code: `crates/mini_racer_engine/src/process/sources.rs`; `crates/mini_racer_engine/src/text.rs` (`units`); `crates/mini_racer_engine/src/sys.rs` (`external_string`, `release_one_byte`, `release_two_byte`, `Filling`); `crates/mini_racer_engine/src/runner.rs` (`shared_source`, `shares_sources`, `Runtime::reader`); `crates/mini_racer_engine/src/process/fork.rs` (`Generation`). Tests: `crates/mini_racer_engine/tests/shared_sources.rs`, `crates/mini_racer_engine/tests/shared_sources_full.rs`, `crates/mini_racer_engine/tests/shared_sources_eviction.rs`, `test/ruby/shared_sources_test.rb`, `test/ruby/shared_source_heap_stats_test.rb`, `test/diff/corpus/shared-sources.json`, `test/stress/shared_load.rb`, `test/stress/one_off_load.rb`. Overview: `ARCHITECTURE.md` "Shared sources".

A script of a megabyte or more reads its source, from its first sighting and under the code cache's key, from one copy in `process::sources`, one byte a unit when every unit fits Latin-1 and two otherwise, as V8 stores a string of it. V8 reads a string's units for as long as the string lives and releases its reference through `sys::release_one_byte` or `release_two_byte` once, on whatever thread runs it: in a collection, in an isolate's teardown, or when it internalizes a live string, which hands the units to the internalized string or, if that one has its own, releases them then (`MigrateExternalString` in V8's `string.cc`), so those touch only the `Arc`'s count.

The list drops a source only once its count is back to `held`, the references its own list and every ancestor's hold, so V8 never frees one: a forked child adds a reference to its parent's, never touches the parent's list and frees nothing it inherited, and an isolate a control block leaks keeps its strings' references.

A copy no string reads that only one context ever read, as a script evaluated once has, goes at the next `Sources::units` call, that is the next large eval of a source shared or kept (`reading` takes the list's lock but sweeps nothing), which looks its own source up first; contexts are told apart by `Runtime::reader`, recorded under the list's lock (`Readers`), since V8's releases touch only the count.

A copy no string reads that two or more contexts have read, read in turn or at once, a copy made again of one of the last 8 sources swept (`List::swept`), so short-lived contexts loading two scripts in turn convert each twice and then keep both, and every copy a forked child inherited stay resident, up to 8 sources or 256 MiB, until a new source needs its room: going idle and `low_memory_notification` release nothing, and a forked child that evicts an inherited copy drops only its own reference, so the copy stays for that process's life; one that inherited contexts it refuses still read counts as read there for good.

Past 8 sources or 256 MiB still read, a context keeps its own copy, as do one with `max_memory:`, whose heap holds mini_racer's copy, and invalid UTF-8, whose replacements are left to V8's decoder; room is decided under the lock before a source is converted, from the fewest bytes it can take or, for one converted before and refused, invalid UTF-8 included, the size the list remembers. `MINI_RACER_RS_CODE_CACHE=off` turns sharing off with the cache. A context reading a shared source reports it in `heap_stats`' `external_memory`, by its length in characters, and not in its `used_heap_size` (`behavior:shared-source-heap-stats@ruby`).
