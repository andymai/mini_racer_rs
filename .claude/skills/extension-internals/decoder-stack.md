# The decoder's stack checks

Code: `ext/mini_racer_rs/src/decode.rs` (`RubyVisitor::check_stack`, `init`); `crates/mini_racer_wire/src/decode.rs` (`entry_key`, `value`); `ext/mini_racer_rs/src/host.rs` (`RubyHost::run`, `message`); `ext/mini_racer_rs/src/rb_raw.rs` (`stack_exhausted`); `ext/mini_racer_rs/src/errors.rs` (`stack_exhausted`). Tests: `test/ruby/stack_test.rb`, `test/ruby/stack/`, `ContextDeepResultsTest` in `test/ruby/context_test.rb`.

The decoder recurses once per level of a result, up to 95, and of a callback's arguments, up to 96 with the arguments array, as mini_racer's limits fall, so whatever its recursive functions keep inline is repeated on the stack of the fiber or thread that decodes: in a release build that is `value` and the container being read, about 300 bytes a level for every shape, so a result 95 deep needs about 30 KiB past the point where Ruby refuses a method call, where mini_racer 0.22.1 needs about 10. A key is read in `entry_key`, out of line, and read again by `value` when it is not a string, since handing `value` its tag split `value` in two and pulled every container into one frame over twice as large; `Pairs::start` and `KeyCache::start` make the decoder's buffers out of line too.

A stack that runs out under Rust frames faults, and Ruby's handler jumps over them to raise, so nothing they own is freed and a lookup or a context's lock they hold is never released. Instead, a container that begins deeper than any checked before asks Ruby whether less than its margin for a C function is left (`RubyVisitor::check_stack`, `rb_raw::stack_exhausted`), as a callback does before decoding its arguments (`RubyHost::run`), and both raise `SystemStackError` with Ruby's `stack level too deep` as an ordinary error (`behavior:stack-exhaustion@ruby`). A callback refused there has no room left to call `to_s`, so `message` hands JavaScript that text itself.

Every class a decode or its errors name is resolved at load (`decode::init`, `encode::init`, `errors::init`, `gc_root::init`), since a `StaticRoot` resolved first near the end of the stack panics on the `SystemStackError` its lookup raises. `ContextDeepResultsTest` in `test/ruby/context_test.rb` decodes each shape 95 deep in a fiber and a thread at Ruby's default stack sizes, and `test/ruby/stack/` converts results and callback arguments 95 deep at gaps short of the end of Ruby's smallest stacks; a debug build's frames are many times larger, so it refuses every one of those.
