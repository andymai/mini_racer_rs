# `MiniRacerRs.timeout` scopes

Code: `ext/mini_racer_rs/src/timeout.rs` (`leave_inherited`); `ext/mini_racer_rs/src/options.rs` (`timeout`); `ext/mini_racer_rs/src/rb_raw.rs` (`yield_setting`); `ext/mini_racer_rs/src/gc_root.rs` (`spawn`); `crates/mini_racer_engine/src/context.rs` (`ScriptOptions`, `nested`); `crates/mini_racer_engine/src/control.rs` (`ContextConfig::timeout_within`, `Timer`); `crates/mini_racer_engine/src/process/watchdog.rs` (`ends_within`, `schedule_nested`); `crates/mini_racer_engine/src/runner.rs` (`Timed`, `arm_timeout`, `rearm_timeout`); `crates/mini_racer_sync/src/termination.rs` (`time_nested`, `untime_nested`). Tests: `crates/mini_racer_engine/tests/eval.rs`, `test/ruby/timeout_scope_test.rb`.

`MiniRacerRs.timeout(milliseconds) { }` checks its milliseconds as `timeout:` checks them. The scope is kept in fiber storage, set before the yield and restored as an `ensure` clause would, inside `rb_ensure` under `rb_protect`, so a pending break or throw survives the restore (`rb_raw::yield_setting`). Fibers and threads started inside the block inherit it while it is open, but a thread the extension starts leaves it before it runs (`timeout::leave_inherited`, from `gc_root::spawn`). The process counts its open scopes, which lets a dispatch skip reading one.

A script dispatch is given the scope's timeout (`ScriptOptions`), which tightens the context's (`ContextConfig::timeout_within`) and is armed as `timeout:` is, for the script and its leftover microtasks. A nested script's own timeout is stacked in the watchdog and the termination cell apart from the outermost script's, whenever it ends before every deadline around it (`ends_within`, `schedule_nested`), and its firing never drops a timeout around it that fired too.
